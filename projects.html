PART ONE

At work: tools that fixed slow testing

Internal IDEMIA tools · I can describe them publicly, but the source code stays private.

NVM Endurance Automation

The problem. SIM endurance tests needed a person to cycle modems by hand for hours.

What I built. A Python tool that drives the modem over AT commands for 24 hours: 5G auth, hourly 4G switch, reset every four hours.

What changed. Tests now run overnight and on weekends. It's used in about 90% of NVM projects.

Python · pyserial · AT commands

eUICC Provisioning Tool

The problem. Provisioning eSIM profiles meant hand-editing XML in SOAP UI and copying transaction IDs between calls.

What I built. A Django app with one-click create → provision → commit on SM-DP, AID management on SM-SR and guard rails.

What changed. It's now the team's main way to provision ICCIDs.

Django · PostgreSQL · SOAP / REST · LDAP

OBTANA Web

The problem. Sending an OTA SMS update required a 2G handset at your desk — and there weren't enough.

What I built. A web service with handsets on the server, one MQTT topic per handset and a Redis queue for busy moments.

What changed. Any tester can send OTA updates from any desk.

Flask · MQTT · Redis · MongoDB

Read the write-up →

NVM Script Editor

The problem. Turning a COMPRION log into a runnable test script took one to two days of manual work.

What I built. A Streamlit tool that converts logs to .pcom scripts, checks the M2M flow and applies TLS-PSK edits.

What changed. The same job now takes minutes.

Streamlit · LDAPS · Docker

FEATURED · CLIENT PROJECT · 2024

Smart Greenhouse Subang

The problem. Farmers' automation went dark whenever the internet dropped, and nothing measured light or CO2.

What I built. As project lead: a control panel with manual fallback and a network watchdog, a CO2 + light sensor node, and a motorized shading net. I designed the panel and co-wrote both firmwares.

What changed. It runs at five greenhouse locations today, used by farmers every day.

ESP32 · FreeRTOS · custom TCP protocol · Telegram
